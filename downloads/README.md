# Web eBook edition

`infinite-ai-context-web.pdf` is the free screen-reading edition of *Infinite
AI Context*. It is a 160-page, 6×9-inch PDF optimized to remain below 10 MB for
easy browser download.

This is a separate distribution rendition. It is derived from the private,
full-resolution print interior but does not replace or modify the Lulu-ready
interior proof. Text, page order, and page size are preserved; the page imagery
is intentionally reduced for web delivery.

# Web eBook edition

`infinite-ai-context-web.pdf` is the free screen-reading edition of *Infinite
AI Context*. It is a 160-page, 6×9-inch PDF optimized for browser download
while preserving selectable, vector PDF text.

This is a separate distribution rendition. It is derived from the private,
full-resolution print interior but does not replace or modify the Lulu-ready
interior proof. Text, page order, and page size are preserved; only the cover,
part, and chapter artwork is reduced to high-quality JPEG at approximately
300 PPI for web delivery.

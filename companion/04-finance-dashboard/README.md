# Finance Dashboard Lab

Local-only, synthetic-data companion for Chapter 4 of *Infinite AI Context*.

Open `starter/index.html` in a modern browser. The project contains no network calls, accounts, uploads, credentials, or financial advice. Use the prompt in `prompts/first-task.md` only from the project folder, after reading its `knowledge/` files.

Expected first outcome: fictional planned, spent, and remaining values render for every category, including the empty Transport category.

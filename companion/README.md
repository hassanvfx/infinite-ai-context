# Infinite AI Context companion package

This local package is the source for the public companion at
<https://hassanvfx.github.io/infinite-ai-context/> and its repository at
<https://github.com/hassanvfx/infinite-ai-context>. It contains no deployment
tracking, data collection, or private book-production material.

## Start here

1. Install Git, a code editor, and a terminal. Developers can also install Node,
   Xcode, or Ollama for the relevant labs; non-developers can begin with the
   Markdown-based knowledge, fiction, or public-claims exercises.
2. Choose one chapter directory below.
3. Open its `README.md`, then tell your installed ClineFlow agent, “Check the
   journal and help me continue.” For a genuinely new task, say, “Start a
   journal for this task.”
4. Use the supplied plain-language prompt. Approve a small plan, define
   success, run the named check, and ask the agent to update the journal.

## The shared ClineFlow loop

Every lab uses the same project-memory cycle:

```text
locate → understand → introspect → plan → define success → ground → execute →
verify → journal → continue
```

The durable context is in the repository—not in a particular agent’s chat
history. Once ClineFlow is installed, it automatically uses the project rules,
context records, and relevant history in the background. You speak normally;
the journal is the only continuity tool you need to name. The human remains
responsible for approvals, claims, creative canon, sensitive-data boundaries,
and review.

## Shared safety checklist

- [ ] Use only the synthetic/example material supplied by the lab.
- [ ] Do not paste credentials, financial records, client material, private work,
  or personal data into a prompt.
- [ ] Start with a read-only discovery prompt.
- [ ] Approve a small plan and state observable success criteria before editing.
- [ ] Run the relevant local check and journal what actually happened.
- [ ] Preserve unresolved questions rather than asking an agent to invent answers.
- [ ] Do not publish, deploy, connect services, or add tracking without a separate authorization.

The legal training matter is not legal advice and must never be used with real
client or case data. The finance examples are not financial advice. The fiction
lab leaves canon with the human author.
